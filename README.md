# 작년 이맘때 내 할 일 (웹페이지)

과거에 받은 메일(`.eml`)을 브라우저에 끌어다 놓으면, **작년·재작년 같은 월·주차**에 받은 메일을 사내 LLM 이 읽고
그때 했던 일을 **올해 이번 주 / 다음 주 / 이번 달**에 챙길 일로 보여주는 웹페이지입니다.

예) 오늘이 2026년 10월 10일(10월 2주차)이면

| 화면 | 비교하는 지난해 메일 |
|---|---|
| 이번 주 (10/5~10/11) | 2025년·2024년 **10월 2주차** 메일 |
| 다음 주 (10/12~10/18) | 2025년·2024년 **10월 3주차** 메일 |
| 이번 달 (10월) | 2025년·2024년 **10월 전체** 메일 (주차별로 묶어 표시) |

- **주차**: 월요일 시작, 그 달 1일이 든 주가 1주차 (예: 2026-10-05(월)~11(일) = 10월 2주차).
  달이 바뀌는 주는 두 달의 주차를 모두 봅니다 (예: 9월 5주차 · 10월 1주차).
- 해마다 같은 일(예: 예산안 제출)은 하나로 묶고 `2024·2025 매년` 으로 표시합니다.
- 올해 받은 메일은 비교 대상이 아니라 분석하지 않습니다. 같은 시기가 아닌 지난해 메일도 LLM 에 보내지 않아 빠릅니다.

- **설치 불필요**: 파이썬 표준 라이브러리만 사용 (Python 3.10 이상). 파일은 `mail_web.py`(서버·분석) + `index.html`(화면) 두 개
- **빠름**: 지난해 같은 시기의 메일만 분석, LLM 요청 4개 동시 처리, 생각(thinking) 생략 요청, 자동 알림 메일은 LLM 생략
- **다시 분석은 즉시**: 한 번 분석한 메일은 결과를 PC(`.cache/`)에 저장 → 다음에는 새 메일만 LLM 에 보냄

## LLM 서버

| 항목 | 값 | 바꾸는 곳 |
|---|---|---|
| 주소 | `http://75.12.15.121:8000/v1` (사내 vLLM, OpenAI 호환) | `mail_web.py` 맨 위 `BASE_URL` 또는 환경변수 `LLM_BASE_URL` |
| 모델 | `thinkingcap` | `MODEL` 또는 `LLM_MODEL` |
| API 키 | 필요 없음 (인증 헤더를 보내지 않음) | 필요해지면 `LLM_API_KEY` |

PC 에 사내 프록시가 설정돼 있어도 LLM 서버에는 **프록시를 거치지 않고 직접 연결**합니다 (프록시 403 방지).
화면 오른쪽 위 `LLM 연결됨 / 연결 안 됨` 표시를 누르면 연결을 다시 확인합니다.

## 실행

**VS Code**: 이 폴더를 열고 `mail_web.py` 에서 ▶ (또는 F5 → `메일 할 일 웹페이지`) → 브라우저가 자동으로 열림 (`http://127.0.0.1:8780`)
**Windows**: `run.bat` 더블클릭
**터미널**: `python mail_web.py`

1. **메일 올리기**: `.eml` 파일이나 폴더를 끌어다 놓기 (파일/폴더 선택도 가능)
   - 파일마다 분석 대상 / 제외(2년 초과, 날짜 없음, 읽기 실패)와 이유가 표시됩니다.
2. **분석하기**: 화면에 올해 이번 주·다음 주·이번 달이 지난해 몇 월 몇 주차와 비교되는지 표시됩니다. 내 이름·메일을 넣고 [분석하기]
3. **결과**
   - 상단 카드(이번 주 / 다음 주 / 이번 달)를 눌러 전환
   - 할 일: 우선순위(긴급·보통·낮음), 근거 메일(몇 년 몇 월 몇 주차, 날짜, 당시 기한) — 체크하면 올해 완료로 기억(브라우저)
   - `할 일은 없었지만 이 시기에 받은 메일` 도 펼쳐 볼 수 있음
   - 분석한 지난해 메일: 한 줄 요약·키워드·주차, 검색, '할 일 있는 메일만' 보기
   - 메일 제목을 누르면 **원문**(회신 인용 포함, HTML 메일은 글자로만) 표시

## 규칙

- 오늘로부터 **2년이 지난 메일**(그래서 재작년 메일은 오늘 이후 날짜분만 해당), **발송 날짜를 알 수 없는 메일**은 분석하지 않습니다.
- 날짜는 `Date` 헤더(표준·ISO·한국어 형식) → 없으면 `Received` 헤더에서 찾습니다.
- 자동 알림·뉴스레터·반송 메일(no-reply, List-Unsubscribe 등)은 LLM 에 보내지 않고 목록에 `자동 알림` 으로만 표시합니다.
- 메일 묶음이 모델 길이 한도를 넘거나 응답이 잘리면 자동으로 나눠 다시 요청합니다.
- 메일 본문은 사내 LLM 서버로만 전송되며, 본문 속 지시문은 따르지 않도록 지시합니다. 결과는 원문으로 확인하세요.
- 서버는 내 PC(`127.0.0.1`)에서만 접속되며, 다른 사이트에서 오는 요청은 거부합니다. 올린 메일은 임시 폴더에 두었다가 종료 시 삭제합니다.
- 저장된 분석 결과(`.cache/`)는 화면 맨 아래 `저장된 분석 결과 지우기` 로 지울 수 있습니다.

## 설정 (`mail_web.py` 맨 위)

`WORKERS`(동시 요청 수, 기본 4 — 서버 여유가 있으면 늘리면 빨라짐), `BATCH_CHARS`, `BODY_CHARS`, `MAX_TOKENS`, `NO_THINK`, `PORT`(기본 8780)
