# 메일 체크리스트 — 라이트 버전

저장된 메일(`.eml` / Outlook `.msg`)을 사내 vLLM 서버(`thinkingcap`)로 분석해 **이번 주·다음 주 할 일**, 메일별 한 줄 요약,
키워드를 HTML 파일 하나로 보여주는 프로그램입니다. 파일 하나(`mail_lite.py`)로 동작하고 **설치할 것이 없습니다**(Python 3.10 이상).

> 웹 업로드 화면·시기별 키워드 추이·월별 흐름 요약 등이 있는 전체 버전은 `ccr-75d69778-yhhne5` 브랜치에 있습니다.

## 실행 (VS Code)

1. 이 브랜치를 받아(Code → Download ZIP) 압축을 풀고 VS Code 에서 **폴더 열기**
2. `mail_lite.py` 를 열고 오른쪽 위 ▶ (또는 F5 → `메일 체크리스트 (라이트)`)
3. 폴더 선택 창에서 메일 폴더 선택 → 분석 → 결과 HTML 이 브라우저로 열림
   (결과 파일은 메일 폴더 옆에 `메일체크리스트_날짜.html` 로 저장)

명령행: `python mail_lite.py <메일폴더> --weeks 8 --me "홍길동 <gildong@corp.com>"`

## 설정

`mail_lite.py` 맨 위 **설정** 부분만 고치면 됩니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| `BASE_URL` | `http://75.12.15.121:8000/v1` | vLLM 서버 주소 (환경변수 `LLM_BASE_URL`) |
| `MODEL` | `thinkingcap` | 모델 이름 (환경변수 `LLM_MODEL`) |
| `API_KEY` | (없음) | 필요할 때만 (환경변수 `LLM_API_KEY`) |
| `ME` | (없음) | 본인 이름/메일 — 누구의 할 일인지 판단 |
| `WEEKS` | 4 | 최근 몇 주 메일을 볼지 (최대 104주 = 2년) |
| `WORKERS` | 4 | LLM 동시 요청 수 — 서버가 여유 있으면 늘리면 더 빠름 |
| `NO_THINK` | True | 생각(thinking) 생략 요청 (지원 안 하는 모델이면 자동 무시) |

## 동작 규칙

- 2년이 넘은 메일, 날짜를 알 수 없는 메일은 분석하지 않습니다.
- LLM 서버에는 PC 의 프록시 설정을 거치지 않고 직접 연결합니다 (사내 프록시 403 방지).
- 자동 알림·뉴스레터·반송 메일은 LLM 에 보내지 않고 목록에만 `자동 알림` 으로 표시합니다.
- 메일 묶음이 모델 길이 한도를 넘거나 응답이 잘리면 자동으로 나눠 다시 요청합니다.
- 메일 본문은 사내 LLM 서버로만 전송됩니다. 본문 속 지시문은 따르지 않도록 지시되어 있지만, 결과는 원문으로 확인하세요.
